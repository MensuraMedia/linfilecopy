LinFileCopy mockups

Ten screens that show how the GTK 3 app will look and behave before any UI code is written. Every icon on this page is a Phosphor SVG read from the local asset folder and inlined here, using the same icon IDs the app will ship with. Fonts are the system's own (Cantarell on GNOME); nothing is fetched from the network.

The windows follow your light or dark theme, the same way the app follows the desktop setting. Tags under each heading show which features the screen covers: B1–B10 are the basic features and #1–#20 are the advanced ones.
